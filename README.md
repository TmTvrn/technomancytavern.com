# Technomancy Tavern

Splash page for [technomancytavern.com](https://technomancytavern.com): a single-file, canvas-rendered pixel-art scene featuring Mancy, the tavern's technomancer barkeep.

- The splash lives entirely in `index.html`; no build step.
- Everything else (`/games/`, `/devlog/`, the Esper Elfy: Save Sparky workbench, art-studies index, posts) is generated by `python3 tools/build.py` from `content/posts/*.html` and `assets/site.css`, and the output is committed. To add a post: drop `content/posts/<slug>.html`, add a `POSTS` entry in `tools/build.py`, run it.
- The demo pages (`realms/`, `studies/`, `art/*.html`) are generated in the game repo and synced in by `docs/devlog/build/publish.sh`.
- Cloudflare Pages (project `tmtvrn`) deploys every push to `main`. Pushes to other branches get preview URLs on `tmtvrn.pages.dev`.
- `tmtvrn.com` and both `www` hosts redirect here (Cloudflare redirect rules, not this repo).
- Set `STEAM_URL` near the top of the script once the Steam page exists.

Run locally:

```bash
python3 -m http.server 8787
```
