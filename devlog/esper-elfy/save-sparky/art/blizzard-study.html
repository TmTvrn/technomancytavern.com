Blizzard Study

One snowstorm in the arena, run by a single simulation and drawn two ways. Same flakes, same gusts, same boss shot, frame for frame. Only the drawing changes.

Grayscale is the game's own value check: the fight must still read without color.
The hybrid borrows methods from pixelfx (MIT): layered streaks, gust waves, ramps and phased impacts. The drawing code on this page is written from scratch, so the look can go into a CC0 release as our own.
