Skull Detail Ladder

One skull at eight sprite sizes, each shown at the same size on screen. With detail per size on, each step up adds features drawn in whole pixels, the way a pixel artist would. Switch to the same math everywhere to see the earlier approach, which turns smooth and vector-like as it grows.

Why the big ones stay pixel art

  • Details are sized in pixels, not in skull units. A crack is always one pixel wide, so at 128 it is a fine hairline instead of a thick smooth stroke.
  • Shading uses a handful of hard color steps, with a checker dither only along the edge between two steps, never as a gradient.
  • The outline changes with the light: near-black on the shadow side, a dark bone color on the lit side. Pixel artists call this selective outlining.
  • Bigger sprites get more steps and more features, not just smoother curves.

What this means for the game

  • Pick one or two sprite sizes per thing and give each its own detail rules, instead of one shape that scales.
  • Everything is still code. Each rule is a few lines, so a new skull variant or a corrupted version is a parameter change, not a redraw.
  • In Godot this runs once per size at load time and is stored as a texture, so it costs nothing while playing.
